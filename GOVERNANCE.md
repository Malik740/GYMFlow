# Governance

## Project Maintainer
GymFlow is currently maintained by a single project owner who is responsible for reviewing contributions, managing releases, and making final project decisions.

## Decision Making
All decisions are made based on what best supports the project. When evaluating a proposed change, the following factors are considered:

- Benefit to users and the project.
- Impact on the existing system.
- Code quality and maintainability.
- Compatibility with the current architecture.

Constructive feedback and different viewpoints are always welcome before a final decision is made.

## Contributions
Contributions are encouraged through issues and pull requests. Contributors should:

- Follow the project's coding standards.
- Keep changes focused and well documented.
- Update documentation when necessary.

Each contribution is reviewed before being merged into the main branch.

## Future Governance
As the project grows, trusted contributors may be invited to help review pull requests and participate in project decisions.
